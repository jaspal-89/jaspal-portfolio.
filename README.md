# Jaspal — Video Editor & Creative Producer

A premium, dark, motion-driven portfolio for Jaspal. The original portfolio architecture is preserved while the personal branding, content structure and project system are customized for an image-free video editing portfolio.

## Tech

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lenis

## Run locally

```bash
bun install
bun dev
```

## Updating portfolio projects

Edit `src/db/projects.ts`. Add a project object, choose one or more categories, and paste the YouTube/Shorts URL into `video_link`.

Categories:

- Clean Edits
- Captions
- UGC Ads
- Faceless
- Promotional
- Motion Graphics
- AI Video

The project UI intentionally does not require image thumbnails.
